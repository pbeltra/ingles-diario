# 🇺🇸 Inglés diario

App sencilla para practicar inglés todos los días, hecha para Pablo.

**Abrir:** https://pbeltra.github.io/ingles-diario/

## Qué hace
- **Inicio:** si ya practicaste hoy, tu racha 🔥 y un calendario de tus días de práctica.
- **Practiqué hoy:** marca el día y envía un “HECHO” (se abre GitHub para crear el aviso) para que Ingles lo registre.
- **Tarjetas:** escuchas la palabra en inglés, piensas qué significa y tocas para ver el español con una frase corta. Te calificas con *Lo sabía / Casi / No lo sabía*. Las que te cuestan vuelven pronto y las que sabes vuelven después (repaso espaciado, sistema Leitner).
- **Modo “Solo oído”:** primero solo escuchas, sin ver la palabra.
- **Progreso:** cuántas palabras ya sabes, cuántas estás aprendiendo y cuántas faltan.

## Tus rutinas
- 5:00 AM: conversación en tu chat con Ingles (todos los días).
- 7:00 PM: vocabulario de oído en tu chat (lunes a viernes).

Tu avance se guarda solo en el navegador de tu teléfono.

## Agregar palabras
En `index.html`, busca la lista `WORDS` al inicio del código y copia una línea:
`{en:"water", es:"agua", ex:"I need water.", exEs:"Necesito agua."},`
